# 설렉 · 아침 준비 가이드북

작성·공식 문서 확인: **2026-10-23** · 대상: 계정이 아직 없는 운영자 · [화면으로 보기](morning-setup-guide.html)

아침의 목표는 **비용을 들이기 전에 앱의 핵심 흐름을 직접 확인하고, 무료 계정으로 실제 서버 검증을 준비하는 것**입니다. Apple Developer 유료 가입은 지금 필수가 아닙니다. 현재는 로컬 구현·검증을 마친 상태이며 완성·출시 준비 완료로 판정하지 않았습니다.

## 1. 앱 직접 확인과 전체 진행 순서

1. 현재 웹 구현을 직접 사용해 사진 선택 → 친구 선택 → 결과 확정 흐름과 디자인을 검토합니다. 목업과 실제 구현을 구분하고 아쉬운 점을 먼저 수정합니다.
2. Supabase Free 테스트 프로젝트를 준비하고 제가 서버를 연결해 실제 공유·접근 권한·삭제를 검증합니다.
3. OpenAI API로 안전 검사 연결을 준비하고 Expo Free 계정을 만듭니다. 안전 검사도 실제 연결해 확인합니다.
4. 운영자·문의처와 테스트 iPhone 사용 가능 여부를 정합니다. 아직 Apple 유료 결제는 보류합니다.
5. 핵심 웹 흐름·실서버·안전 검사 검증을 통과하고, 사용자가 iPhone 설치 검증까지 진행할 가치가 있다고 판단하면 Apple 유료 가입을 결정합니다.
6. 그 후 서명된 iPhone 앱에서 원본 앨범 저장·권한·복구를 검증하고 TestFlight·심사 준비를 마무리합니다.

**지금 준비물:** 인증 가능한 이메일, 비밀번호 관리자, 앱을 검토할 브라우저. 테스트할 iPhone은 사용 가능 여부만 확인합니다. Apple 본인 확인 자료·결제수단은 유료 가입을 결정한 뒤 공식 화면에서 준비합니다.

**먼저 직접 볼 것:** 버튼과 화면 수가 충분히 줄었는지, 친구가 설명 없이 선택을 제출할 수 있는지, 결과를 보고 최종 결정을 내리기 쉬운지 확인합니다. 로컬 미리보기는 개발 서버 실행 중에만 접근할 수 있습니다. 접속이 안 되면 미리보기 재실행을 요청하면 됩니다. 목업의 동작만으로 실제 공유나 iPhone 앨범 저장이 검증됐다고 판단하지 않습니다.

**다음 단계로 넘어갈 기준:** 사용자가 현재 핵심 흐름을 확인하고, 먼저 고칠 문제를 정리한 상태. 아래 무료 계정 준비는 함께 진행할 수 있으며, 서버 통합·보안 검증은 제가 이어갑니다.

## 2. Supabase Free — 실제 서버 검증 준비

**시작:** [Supabase 대시보드](https://supabase.com/dashboard) · [요금](https://supabase.com/pricing)

1. 가입·이메일 인증 후, 본인이 소유하는 조직을 만듭니다. 초기 테스트는 Free 플랜으로 시작합니다.
2. 새 프로젝트를 만듭니다. 이름은 예를 들어 `seollek-test`로 지정합니다. 이는 제안 이름이며 아직 생성된 프로젝트가 아닙니다.
3. DB 비밀번호는 강한 자동 생성값을 사용하고 비밀번호 관리자에 저장합니다. 채팅으로 보내지 않습니다.
4. 한국 이용자 중심의 초기 테스트라면 **Specific region → Seoul** (`ap-northeast-2`)을 우선 검토합니다. 선택 목록에 없으면 임의로 다른 지역을 확정하지 말고 가능한 지역을 알려주세요. 실제 선택 지역을 기록합니다.
5. 프로젝트 준비가 끝나면 대시보드에서 프로젝트 이름·Project Reference·지역을 확인합니다. Connect 또는 API Keys에서 프로젝트 URL과 앱용 공개 키의 위치만 확인해 둡니다.

지역은 기본 데이터 저장 위치와 관련되므로 이후 개인정보 안내에 반영합니다. 서울을 선택해도 외부 안전 검사 등 모든 처리가 국내에만 남는다는 뜻은 아닙니다. [지역 안내](https://supabase.com/docs/guides/platform/regions)

**키 구분:** 앱에는 publishable 공개 키를 사용하고, secret/service_role 관리자 키는 넣지 않습니다. 현재 코드의 환경변수 이름은 `EXPO_PUBLIC_SUPABASE_ANON_KEY`이므로, 새 키 체계와 Edge 인증 호환성은 연결할 때 제가 확인합니다. 공식 문서는 기존 anon/service_role 키를 2026년 말까지 폐기 예정으로 안내하고 있습니다. 오래된 튜토리얼을 따라 관리자 키를 앱에 붙여 넣지 마세요. [키 안내](https://supabase.com/docs/guides/getting-started/api-keys)

**완료 기준:** 빈 테스트 프로젝트가 정상 실행되고, 이름·지역·Reference를 확인할 수 있음. SQL 실행, Storage 공개 전환, RLS 해제, 익명 Auth 설정은 직접 하지 않아도 됩니다. 제가 기존 네 개의 migration과 서버 코드를 연결합니다.

**비용/운영:** Free는 테스트 출발점입니다. 공식 안내상 1주 비활동 시 일시 중지될 수 있어 심사·운영 환경은 별도로 점검해야 합니다. 실제 사진은 용량과 전송량을 사용하므로 출시 플랜은 사용량을 보고 결정합니다. [현재 요금·제한](https://supabase.com/pricing)

## 3. OpenAI API — 안전 검사 연결 준비

**시작:** [API 플랫폼](https://platform.openai.com/) · [API 키 화면](https://platform.openai.com/api-keys)

1. API 플랫폼에 로그인하고 설렉용 프로젝트를 준비합니다. ChatGPT와 같은 로그인 계정을 쓰더라도 API 설정은 별도로 확인해야 합니다.
2. 프로젝트용 API 키를 생성하면 비밀번호 관리자에 즉시 저장합니다. 전체 키는 생성 시에만 표시됩니다. [키 관리 안내](https://help.openai.com/en/articles/4936850-where-do-i-find-my-openai-api-key)
3. 키는 나중에 본인이 Supabase Edge Function secrets의 `OPENAI_API_KEY`에 직접 입력합니다. 입력 위치까지 제가 안내할 수 있습니다. 앱 `.env`, HTML 안내서, Git, 채팅에 키를 넣지 않습니다.
4. 프로젝트에서 해당 API 사용이 가능한지 확인합니다. 권한/계정 제한이 나오면 키를 가린 오류 내용만 알려주세요. 검사 우회로 해결하지 않습니다.

설렉은 사진 원본 대신 서버가 선택한 미리보기와 부탁 문구를 `omni-moderation-latest`로 검사하도록 구현했습니다. 현재 공식 문서상 독립 Moderation endpoint는 무료입니다. 다른 생성 API 사용 비용과는 별개이며 실제 접근·한도·응답은 연결 후 검증합니다. [Moderation 안내](https://developers.openai.com/api/docs/guides/moderation)

**ChatGPT 유료 구독을 추가로 결제할 필요는 없습니다.** ChatGPT와 API 과금은 분리되어 있습니다. API 결제수단이나 선불 충전을 요구받으면 현재 계정 조건을 확인한 뒤 진행하세요. [과금 안내](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)

**완료 기준:** API 프로젝트·키 준비 여부 확인. 지금 비밀값을 전달할 필요는 없습니다. 키 누락이나 검사 오류 시 공유가 막히도록 되어 있어, 실제 검사 연결은 출시 전 필수입니다.

## 4. Expo Free — 이후 iPhone 빌드 준비

**시작:** [Expo 가입](https://expo.dev/signup) · [공식 빌드 안내](https://docs.expo.dev/build/setup/)

1. 설렉에 사용할 Expo 계정을 만들고 이메일 인증을 완료합니다. 이미 계정이 있으면 재사용합니다.
2. 사용자명을 메모하고 브라우저에 로그인해 둡니다.
3. 새 앱 템플릿을 생성하거나 기존 폴더를 덮어쓰지 않습니다. 현재 저장소와 EAS 프로젝트 연결은 제가 이어갑니다.

EAS Build는 Free 플랜에서도 사용할 수 있습니다. 아침에 유료 구독부터 할 필요는 없습니다. 한도·대기열·실제 빌드 조건은 실행 때 확인합니다. [Expo 안내](https://docs.expo.dev/build/setup/)

**완료 기준:** 계정 로그인 가능 + 사용자명 확인. Apple 가입과 Expo 가입은 별개입니다. 현재 Windows 환경에서는 클라우드 빌드 경로로 진행하며, 지금 Mac을 구매할 필요는 없습니다.

## 5. 운영 정보와 테스트 기기

- **공개 운영자명:** 정책·지원 페이지에 공개할 실제 운영 주체를 결정합니다. Apple 판매자명 표시와 별도로 확인합니다. 법인인 것처럼 임의로 표기하지 않습니다.
- **문의 이메일:** 실제 수신·회신 가능한 주소를 정합니다. 별도 문의용 주소를 권장하지만 새 도메인을 구매할 필요는 없습니다. 다른 주소에서 시험 메일을 보내 수신을 확인합니다.
- **신고 담당자:** 초기에는 본인이 맡아도 됩니다. 실제로 신고를 확인하고 삭제·제한·문의 대응을 할 담당자를 정합니다.
- **테스트 iPhone:** 모델·iOS 버전·사용 가능 여부를 알려주세요. 원본 저장, 제한/거절 사진 권한, HEIC/iCloud, 중간 종료 후 재시도는 실제 기기에서 검증해야 합니다.
- **정책:** 이미 결정한 ‘최종 확정 후 서버 30일 보관 + 직접 삭제 가능’을 유지합니다. 확정 전 요청은 이어서 쓰기 위해 남으며, 기기 앨범에 저장된 사본은 서버 삭제로 지워지지 않습니다. 지역·외부 제공자 보관·백업 삭제 조건을 실제 설정과 맞춰 최종 검토합니다.

**완료 기준:** 공개할 운영자명·수신 확인한 이메일·신고 담당자·테스트 기기 확인. 아직 결정하지 못한 값은 미정이라고 남기면 됩니다. 해당 값과 실제 운영 검증이 끝나기 전에는 심사 제출을 완료할 수 없습니다.

## 6. Apple Developer — 검증 통과 후 유료 가입 결정

**지금은 결제하지 않아도 됩니다.** 아래는 나중에 진행할 절차입니다. 먼저 실제 웹·서버 흐름을 확인하고, iPhone 설치 검증으로 넘어갈 때 가입을 결정합니다. 가입 대기 시간을 줄이려고 앱 검토보다 결제를 먼저 할 필요는 없습니다.

무료 Apple 개발자 등록과 유료 Developer Program은 다릅니다. Mac의 Xcode Personal Team으로 제한적인 무료 기기 테스트도 가능하지만, 현재 Windows + EAS 경로에서는 이를 바로 사용할 수 없습니다. TestFlight·스토어 배포를 위한 유료 가입 시점과, 무료로 먼저 확인할 수 있는 범위를 구분합니다. [Apple 계정·테스트 안내](https://developer.apple.com/help/account/basics/about-your-developer-account)

**결제 전 확인할 기준:** 사용자가 실제 구현의 핵심 흐름과 디자인을 수용하고, 테스트 서버에서 공유·권한·삭제·안전 검사가 동작하며, iPhone 테스트 계획과 남은 위험을 확인한 상태. 원본 Photos 저장 등 네이티브 기능까지 모두 검증됐다는 뜻은 아닙니다.

**시작:** [Apple 공식 가입 안내](https://developer.apple.com/programs/enroll/)

1. 앱을 소유할 Apple Account로 로그인하고 이중 인증을 켭니다.
2. 개인/조직 가입을 선택합니다. 개인·개인사업자라면 개인 가입 요건을 먼저 확인하세요. 법인 명의로 출시하려면 조직 가입 요건을 확인합니다.
3. 실제 법적 이름·주소·연락처를 입력하고 본인 확인을 진행합니다.
4. Apple의 안내 순서에 따라 약관과 결제를 직접 처리합니다. 진행 상태와 안내 메일을 확인합니다.
5. 가입 승인 후 [Apple Developer 계정](https://developer.apple.com/account/)과 [App Store Connect](https://appstoreconnect.apple.com/) 접근 여부를 확인합니다.

**결정 전 알아둘 점:** 개인 가입은 본인의 법적 이름이 스토어 판매자명으로 표시됩니다. 앱 이름 ‘설렉’과 판매자명은 별개입니다. 조직 가입은 법인 요건·D-U-N-S 등 추가 확인이 필요합니다. 이름을 감추려고 개인 가입 이름 칸에 브랜드명을 쓰지 마세요. [가입 요건](https://developer.apple.com/programs/enroll/)

**비용:** 공식 기준 연 99 USD, 실제 지역 통화·최종 금액은 결제 화면에서 확인합니다. 승인 완료 시점은 보장할 수 없습니다. 결제·인증·약관 동의는 본인이 진행합니다. [공식 비용](https://developer.apple.com/programs/enroll/)

**지금 완료 기준:** ‘유료 가입 보류’면 충분합니다. 나중에 진행하면 ‘신청 완료 / 확인 중 / 승인 완료’를 알려주세요. 인증서·프로비저닝·앱 식별자 등록은 이후 제가 설정을 이어갑니다. 비밀번호와 일회용 인증 코드는 직접 입력하세요.

## 7. 준비 상태 전달 — Apple 미가입이어도 가능

아래 상태만 복사해서 답하면 됩니다. 비밀번호·API 키·인증 코드·DB 접속 문자열은 제외합니다.

```text
설렉 준비 상태
- 실제 앱 검토: 확인 전 / 수정 의견 있음 / 다음 검증 진행
- Supabase: 준비 완료 / 미정 (프로젝트 이름·Reference: , 지역: )
- OpenAI API: 프로젝트·키 준비 완료 / 설정 도움 필요 / 미정
- Expo: 준비 완료 / 미정 (사용자명: )
- Apple Developer: 유료 가입 보류 / 승인 대기 / 승인 완료
- 가입 유형: 미정 / 개인 / 조직
- 공개 운영자명:
- 공개 문의 이메일: (수신 확인 여부: )
- 신고 담당자:
- iPhone: 모델 / iOS 버전 / 사용 가능 여부
- 막힌 화면: 비밀값을 가린 오류 내용
```

실제 인증은 각 공식 로그인 화면에서 직접 진행합니다. 계정 비밀번호 공유나 관리자 키 전달로 연결하지 않습니다. 비밀값이 노출되면 해당 서비스에서 폐기·재발급하고 서버 설정을 교체합니다.

## 8. 이후 제가 이어갈 일과 남은 출시 조건

| 단계 | 제가 진행할 작업 | 사용자에게 필요한 참여 |
|---|---|---|

현재 로컬 테스트 **57개**, 웹·iOS 번들 생성, 기본 흐름 검증까지 완료된 기록이 있습니다. 실제 서버·사진 앨범 저장·서명·스토어 검증은 남아 있습니다. 의존성 빌드 도구 경고 재검토도 제가 처리할 항목입니다. 계정만 생기면 바로 심사 신청이 가능한 상태라고 보지는 않습니다.

Apple 미가입·승인 대기 → 서버 연결·웹/정책 준비는 진행 가능. OpenAI 미준비 → 로컬 개발은 가능하지만 실제 공유 검사 검증은 대기. 운영자·이메일 미정 → 정책 초안은 유지하되 공개본·심사 자료 확정은 대기. iPhone 미준비 → 기기 검증·출시 후보 확정은 대기합니다.
