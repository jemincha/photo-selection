# 설렉 메인 구조 — 2026-10-10

가제는 **설렉**: 셀렉 + 설렘. 사진을 고르는 기능과 함께한 순간의 감정을 담는다. 첫 화면의 영문 표기는 SEOLLEK으로 두었다. 상표·스토어 이름 사용 가능성 검토는 하지 않았다.

## 화면 구성

- 첫 방문: 브랜드 소개 → 닉네임 → 설렉 시작. 기존 닉네임이 있으면 바로 홈.
- 홈: 진행 중인 내 사진·친구 사진 셀렉, 분류 진행률, 새 앨범 만들기, 최근 앨범.
- 앨범: 전체 앨범을 모바일에서도 2열로 표시. 사진 표지·이름·참여자·상태 제공.
- 친구: 내가 참여한 앨범에서 함께한 사람을 모아 보여주고 공유 앨범으로 이동. 독립 친구 요청·주소록·친구 검색은 추가하지 않았다.
- 마이페이지: 닉네임 변경, 현재 이용 상태. 소셜 로그인 연결은 추후 구현.

네 탭은 메인 화면에서 유지하고, 앨범 상세·사진 상세·업로드·제출은 별도 스택으로 연다. 사진을 고르는 동안 하단은 분류 버튼에 집중한다. 기존 앨범·요청 URL과 데이터 구조는 유지한다.

## 시각 방향

[Ohtt 포트폴리오](https://www.ohttne.com/)의 흰 바탕·검정 타이포그래피·여백·작은 번호 표기를 참고했다. 설렉은 따뜻한 흰색, 검정 행동 버튼, 작은 테라코타 포인트, 사진 중심 카드로 구성했다. 원본의 로고·일러스트·폰트·앱 이름·자산은 가져오지 않았다. 사진 분류 화면의 상태별 색상은 기능 식별을 위해 유지한다.
