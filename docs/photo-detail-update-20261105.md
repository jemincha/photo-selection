# 사진 판단 품질 업데이트

2026-11-05 · 개발·재테스트 안내용. 서버 배포나 스토어 제출 기록이 아니다.

## 변경

- 셀렉 상세와 최종 선택 사진 패널에 핀치 확대(1~4배), 더블탭 확대/축소, 44pt 이상 확대/원래 크기 버튼을 추가했다. 사진 영역은 어두운 배경이다.
- 확대 중 한 손가락 드래그는 사진 내부 이동이다. 원래 배율에서만 오른쪽 다음·왼쪽 이전 탐색을 수행한다. 핀치 종료가 사진 넘김으로 바뀌지 않으며 사진 변경·화면 크기 변경 시 배율을 초기화한다. 기존 이전/다음·분류별 이동과 분류 자동 이동을 유지한다.
- 미리보기 오류 시 다시 불러오기를 제공한다. VoiceOver에는 사진·현재 배율과 확대/탐색 동작을 제공하고 확대 버튼을 별도로 둔다.
- 신규 웹·네이티브 업로드의 미리보기 긴 변 상한을 720에서 1600px로 높였다. 작은 사진은 확대 생성하지 않는다. 원본 파일·체크섬·서버 저장 경로는 유지한다.
- 셀렉 상세에서 다음 두 장을 대기 목록으로 관리한다. 한 번에 한 건만 프리로드하고 빠른 이동 시 대기 목록을 교체한다. 프리로드 실패로 분류를 막지 않는다. 최근 성공 URL은 최대 8개만 추적하며 이미지 캐시 자체는 플랫폼이 관리한다.

## 선택한 범위와 제한

이번에는 기존 공유 미리보기를 목록과 상세에서 함께 사용한다. 720px 목록용과 별도 고해상도 상세용 파일을 추가하는 변경은 하지 않았다. 서버 스키마 변경 없이 새 업로드부터 개선하는 단계이며 목록에서도 더 큰 파일을 읽으므로 전송량·이미지 디코딩 메모리 증가 가능성이 있다. 100장 실기기 측정에서 부담이 크면 목록/상세 저장 분리를 다음 단계로 진행한다.

기존 720px 미리보기는 그대로 표시하며 자동 고화질 변환이나 원본 재업로드를 하지 않는다. 확대 기능은 기존 사진에도 적용되지만 원래 없던 디테일을 복원하지는 못한다. 원본 위치정보 제거·계정 연결·푸시·Universal Links·운영 서버 연결은 이번 구현 범위에 포함되지 않는다. 출시 차단 항목은 기존 출시 증빙에서 계속 추적한다.

## 검증과 재테스트

로컬 lint·TypeScript 검사, 자동 테스트 49개와 웹 production export가 통과했다. 실기기·실서버 검증 상태는 변경하지 않았다.

자동 검사는 확대 경계(가로/세로), 더블탭 복귀, 확대 중 탐색 차단, 핀치 후 한 손가락 전환, 취소된 탭, 프리로드의 동시 처리 제한·대기 교체·실패 재시도를 다룬다. 제스처 검사는 등록된 콜백을 모의 이벤트로 실행하며 실제 브라우저 터치나 네이티브 렌더링을 대체하지 않는다.

실기기에서 다음을 확인한다.

1. 새로 올린 가로/세로 사진의 눈·표정을 확대해 판단한다. 핀치·더블탭·버튼으로 확대/복귀하고 이미지 가장자리로 드래그한다.
2. 확대 중에는 사진이 넘어가지 않는다. 원래 크기로 복귀한 뒤 스와이프·이전/다음·분류별 보기·분류 자동 이동으로 다른 사진을 열면 배율이 초기화된다.
3. 요청자의 최종 선택 패널에서도 확대 후 선택하고, 확정 후 전체 후보를 읽기 전용으로 확인한다.
4. 이전 720px 사진, 작은 사진, HEIC/iCloud 사진, 네트워크 오류·재시도를 검사한다. 새 1600px 미리보기 생성 전후 원본 체크섬이 같은지 확인한다.
5. 100장을 빠르게 이동하고 폴링·화면 회전·백그라운드 복귀를 거친다. 전송량·메모리·발열·응답 시간을 기록한다. 속도 개선 수치는 실제 측정 전 주장하지 않는다.
6. 작은 iPhone·큰 글자·VoiceOver에서 사진, 확대 버튼, 분류 버튼과 홈 영역의 겹침을 확인한다. Safari에서 페이지 전체 확대와 사진 제스처가 충돌하지 않는지 확인한다.
