# 진입 로고·사진 탐색·설정 업데이트

2026-11-05 · 개발·재테스트 안내용

- 진입 로딩은 약 3.4초다. “함께한 설렘을 셀렉”을 먼저 보여주고 주변 글자가 사라져 설·렉이 남은 뒤 “설렉.” 로고가 기울기·착지 눌림·반동과 함께 정착한다. 데이터 초기화가 더 걸리면 로고로 기다린다. 동작 줄이기 또는 설정 확인 실패 시 정적인 로고를 쓴다. Expo Go의 다운로드 화면이나 운영체제의 정적 스플래시는 별개다.
- 홈 로고 아래에 같은 문구를 표시한다. 진행 중 이벤트가 없으면 내용 영역 중앙에 로고를 둔다. 하단 행동은 사진을 올리는 버튼 하나이며 탭 바 안전 여백을 중복 적용하지 않는다.
- 반응 기호는 하트 `♡`, 세모 `△`, X `×`, 투표 전 `·`다. 이벤트 메인은 기호와 개수, 접근성 읽기와 투표 창은 한글 의미를 유지한다.
- 이벤트에서 사진을 열면 화면에 표시한 사진 순서로 좌우 탐색한다. 중복으로 가져온 사진은 한 번만 탐색한다. 원래 크기에서 오른쪽 다음·왼쪽 이전이며 확대 중에는 사진을 이동한다. 핀치 비율을 연속적으로 반영하고 손가락 중심을 유지한다. 최대 8배, 두 번 탭 또는 원래 크기 버튼으로 복귀한다.
- 설정의 닉네임 입력창 우측에 저장을 둔다. 개인정보 및 이용 약관으로 정책 진입을 묶고, 계정 및 보안 안에서 탈퇴와 이벤트 데이터 삭제를 나눈다.
- 이벤트 데이터 삭제는 내 업로드·참여·투표 기록을 지운다. 계정·닉네임·친구 연결과 다른 사람의 사진은 유지한다. 서버 요청별 삭제 대기 작업을 재사용하며 기기 정리가 실패해도 다음 실행에서 이어서 처리한다. 탈퇴는 기존 계정 전체 삭제 경로를 사용한다. 사진 앱에 따로 저장한 사본은 지우지 않는다.
- 도움과 문의에서 버그·제안을 작성한다. 서버 모드는 비공개 문의 테이블에 접수하고 계정당 시간당 10회로 제한한다. 로컬 모드는 기기에 임시 저장했다고 명시하며 전송으로 표시하지 않는다. 실패 시 작성 내용도 남긴다. 운영자 이메일이 설정돼 있으면 이메일 작성도 제공한다.
- 최초 홈 진입에서 사진 생성과 네 탭을 소개하는 두 단계 코치마크를 제공한다. 완료·건너뛰기를 계정별 기기에 저장한다. 앱 재설치나 다른 기기에서는 다시 표시될 수 있다.

## 검증과 남은 작업

모바일 자동 테스트 61개, PostgreSQL 엔진 기반 마이그레이션·권한 테스트 17개, TypeScript·lint 검사, 웹 production export와 iOS Hermes 번들 export 통과. iOS export는 샌드박스 임시 폴더 권한 문제를 일반 실행으로 재검증했다. 이는 서명된 실기기 빌드 검증과 별개다. UI 검사는 실제 컴포넌트를 모의 네이티브 뷰·애니메이션 드라이버로 실행한다. 로딩 시간·대기·동작 줄이기, 코치마크 최초 표시와 완료 저장, 자유 핀치·초점·탐색, 기기 정리 실패 후 복구와 계정 보존, 서버 문의 검증·횟수 제한·데이터 삭제 범위를 확인했다.

실서버에는 아직 배포하지 않았다. 친구·탐색 변경 마이그레이션 `20261105103115_event_navigation_and_friends.sql`과 이번 `20261105115959_account_history_and_feedback.sql`을 순서대로 적용해야 서버 기능을 쓸 수 있다. 문의는 관리자용 비공개 테이블에 저장하며 관리자 알림·전용 접수함 화면은 추가하지 않았다.

iPhone 실기기의 모션 느낌, 핀치 응답, Dynamic Type, 코치마크 위치와 안전 영역은 추가 확인이 필요하다. 기존 720px 미리보기는 자동 재생성하지 않으며 새 업로드의 최대 1600px 미리보기를 사용한다.
