# 설렉 · Apple 유료 가입 전 iPhone 테스트

2026-10-26 · Windows + 실제 iPhone · Apple Developer 유료 가입 보류

**SDK 불일치 해결 후 다시 실행:** 프로젝트를 Expo Go에 맞는 SDK 58로 갱신했습니다. 기존 서버가 열려 있으면 Ctrl+C로 종료하고, `mobile` 폴더에서 `npx expo start --go --clear`를 실행해 **새 QR 코드**로 접속합니다. 이미 로그인했다면 로그인부터 반복할 필요는 없습니다. iPhone 실행과 사진 저장은 다음 접속에서 확인합니다.

## 1. iPhone에서 준비

1. App Store에서 **Expo Go**를 설치합니다. [Expo 공식 설치 입구](https://expo.dev/go)
2. [Expo](https://expo.dev/signup) 무료 계정을 만들고 Expo Go에서 로그인합니다. 기존 계정이 있으면 재사용합니다.
3. iPhone과 개발 PC를 같은 집/개인 Wi-Fi 네트워크에 연결합니다. PC가 유선이어도 같은 내부망에서 기기 간 통신이 가능하면 됩니다. 게스트 Wi-Fi는 피합니다.

Apple 유료 가입·결제·인증서 생성·EAS 빌드는 이 단계에 필요하지 않습니다. Expo Go 안에서 실행되는 네이티브 테스트이며, 설렉 단독 설치파일을 설치하는 방식은 아닙니다.

## 2. PC에서 실행

Windows PowerShell을 열고 다음을 순서대로 실행합니다. 현재 프로젝트에는 Expo 의존성이 설치되어 있어 처음부터 앱을 새로 만들거나 npm install을 반복할 필요는 없습니다.

```powershell
Set-Location -LiteralPath 'C:\Users\jemin\개인작업\40_개발\photo-selection\mobile'
npx expo login --browser
npx expo start --go
```

`expo login --browser`가 연 브라우저에서 iPhone의 Expo Go와 **같은 Expo 계정**으로 로그인합니다. Google로 가입했다면 **Continue with Google**을 선택합니다. 별도 Expo 비밀번호를 만들거나 터미널에 Google 비밀번호를 입력할 필요는 없습니다. 로그인 연결 완료 후 터미널에서 `npx expo whoami`로 계정을 확인하고 다음 명령을 실행합니다. 비밀번호·인증 코드는 채팅에 보내지 않습니다.

이 프로젝트는 `expo-dev-client`를 포함하므로 `--go`를 명시합니다. 터미널에 Expo Go용 QR 코드가 나오면 실행 준비 단계까지 도달한 것입니다. 터미널을 닫거나 PC를 절전 상태로 두지 않습니다. 끝낼 때는 `Ctrl+C`로 정상 종료합니다.

### Windows 브라우저 자동 실행이 실패하면

`cmd.exe /c start ... exited with non-zero code: 1`로 로그인 명령이 종료되면, 자동 브라우저 실행을 끄고 새 로그인 링크를 직접 엽니다. 이전에 실패한 명령의 링크는 사용하지 않습니다.

```powershell
$env:BROWSER = 'none'
npx expo login --browser
```

`Waiting for browser login...` 상태로 터미널이 계속 실행 중인 채로, **이번에 출력된 새 URL 전체**를 복사해 같은 PC의 Edge 또는 Chrome 주소창에 붙여 넣습니다. `Continue with Google`로 로그인하고 CLI 연결을 완료합니다. 링크의 localhost 콜백은 PC를 가리키므로 iPhone에서 열지 않습니다. 로그인 대기 링크는 채팅에 보내지 않습니다.

로그인 성공 후 PowerShell 프롬프트가 돌아오면 다음을 실행합니다.

```powershell
Remove-Item Env:BROWSER
npx expo whoami
npx expo start --go
```

`BROWSER=none`이 브라우저 실행 함수를 건너뛰는 것은 설치된 CLI 코드로 확인했습니다. Google 인증과 콜백 완료는 사용자가 직접 진행한 뒤 확인합니다.

PC 명령 실행은 이 채팅에 맡겨도 됩니다. iPhone 앱 설치·로그인은 본인이 진행합니다.

## 3. iPhone에서 설렉 열기

1. iPhone 기본 카메라로 PC 터미널의 QR 코드를 스캔합니다.
2. Expo Go에서 열기를 선택합니다. 로컬 네트워크 접근을 요청하면 테스트에 필요한 접근을 허용합니다.
3. 처음 코드를 불러오는 동안 기다립니다. 설렉의 시작 화면이 나오면 성공입니다.
4. 개발자 메뉴가 보이면 닫고 앱을 사용합니다. 코드가 수정되면 다시 불러오거나 Fast Refresh로 변경을 확인합니다.

화면을 Safari에서 보는 웹 테스트와 다릅니다. 다만 처음 실행·재로딩에는 PC의 개발 서버 연결이 필요하므로 PC 없이 독립 실행되는 배포판으로 보지는 않습니다.

## 4. 버전·연결 오류가 나면

| 증상 | 다음 행동 |
|---|---|
| 프로젝트/Expo Go SDK 버전이 맞지 않음 | 2026-10-26 사용자의 Expo Go가 SDK 58을 요구하는 것을 확인해 프로젝트를 SDK 58로 갱신했습니다. 갱신 뒤에는 서버를 종료하고 `npx expo start --go --clear`로 새 QR을 생성합니다. 다시 오류가 나면 양쪽 SDK 버전을 알려주세요. iOS 실기기에 옛 Expo Go를 설치해 해결하는 경로는 지원되지 않습니다. |
| Expo 로그인 오류 | PC CLI와 iPhone Expo Go가 같은 Expo 계정인지 확인합니다. |
| QR은 열리지만 서버 접속 실패 | 같은 네트워크인지, iPhone의 Expo Go 로컬 네트워크 접근이 허용됐는지, PC가 깨어 있는지 확인합니다. Windows 방화벽은 해제하지 말고 신뢰하는 개인 네트워크의 필요한 접근만 확인합니다. |
| 캐시/이전 코드가 의심됨 | PC에서 Ctrl+C 후 `npx expo start --go --clear`로 다시 실행합니다. |
| 빨간 오류 화면·모듈 누락 | 오류 문구를 보내주세요. 비밀값·개인 사진이 포함되지 않도록 가립니다. 라이브러리를 무작정 추가하거나 삭제하지 않습니다. |

같은 네트워크에서 연결하기 어려우면 **추가 선택지**로 `npx expo start --go --tunnel`이 있습니다. 외부 터널 서비스를 사용하고 추가 도구 설치가 필요할 수 있으므로 먼저 LAN 연결을 확인합니다. SDK 버전 불일치는 터널로 해결되지 않습니다.

## 5. 첫 테스트는 이 순서로

- 테스트용 사진 몇 장으로 시작 화면 → 사진 선택 → 요청 준비 → 결과 화면의 조작감을 확인합니다.
- 한 손으로 버튼을 누르기 쉬운지, 아래쪽 버튼이 홈 인디케이터와 겹치는지, 글자가 읽히는지 확인합니다.
- 사진 확대·넘기기·스크롤, 키보드를 열고 닫을 때 화면이 가려지는지 확인합니다.
- 사진 선택 권한을 제한하거나 거절했을 때 앱이 복구 방법을 안내하는지 확인합니다.
- 최종 확정과 원본 앨범 저장은 테스트용 사진으로 시도하고, 사진 앱에서 실제 저장 결과를 확인합니다. 성공 전에는 저장 완료로 판정하지 않습니다.
- 앱을 다른 앱으로 전환했다 돌아왔을 때 상태가 유지되는지 확인합니다. 강제 종료·iCloud 원본·HEIC·재시도는 기본 흐름이 동작한 뒤 별도로 기록합니다.

**Supabase 미연결:** 코드에는 로컬 모드가 있어 화면과 단일 기기 흐름부터 확인할 수 있습니다. 다른 사람 폰과의 실제 공유·안전 검사·서버 삭제 성공을 의미하지 않습니다. Supabase 테스트 프로젝트와 서버 설정을 연결한 뒤 여러 기기로 검증합니다. 기존 `.env`에 서버 설정이 들어 있다면 임의로 지우지 말고 현재 모드를 확인합니다.

**Expo Go의 범위:** 현재 사진 선택·앨범 저장용 Expo 모듈은 Expo Go 지원 대상입니다. 실제 설렉 코드의 호환성과 저장 성공은 기기에서 확인해야 합니다. 앱 이름·아이콘·권한 문구·전용 앱 링크·출시판 성능은 별도 서명 빌드에서 다시 검증합니다. Expo Go의 권한을 설렉 단독 앱의 권한 검증과 같다고 기록하지 않습니다.

## 6. 실행 후 알려줄 내용

```text
- iPhone 모델 / iOS 버전:
- Expo Go 버전:
- 시작 화면: 열림 / 오류
- 불편한 동작: 어떤 화면에서 무엇을 했을 때인지
- 사진 선택 / 앨범 저장: 성공 / 실패 / 아직 안 함
- 오류 문구: 비밀값을 제외한 내용
```

이번 완료 기준은 **본인 iPhone에서 설렉 시작 화면이 뜨고 핵심 조작을 직접 확인하는 것**입니다. 이후 실제 서버·여러 기기 검증과 수정을 진행하고, 사용자가 만족하면 Apple 유료 가입 및 별도 iPhone 빌드 단계로 넘어갑니다.
