친구가 골라주는 사진 셀렉

요청자와 친구가 같은 앱에서 참여하는 모바일 와이어프레임입니다. 앱 미설치 친구는 최소 웹 화면으로 참여합니다.

요청자 흐름 시작초대받은 친구 흐름 시작

체험 순서

  1. 소개 → 홈 → 새 요청 → 사진 선택 → 업로드 완료 → 초대.
  2. 초대 화면에서 친구 참여를 체험하고 좋아요·의견을 남깁니다.
  3. 왼쪽 역할을 요청자로 바꾸고 최종 사진을 선택·확정합니다.
  4. 원본 저장의 진행·완료·실패 상태를 확인합니다.

화면 밖의 역할·참여 환경·상태 선택기는 검토 도구입니다. 앱 제품 화면에는 포함되지 않습니다.

전체 화면

S0 소개·로그인S1 홈S2 이벤트 생성S3 초대 공유S4 업로드S5 이벤트·사진 그리드S6 사진 상세S7 최종 선택S8 확정 결과W1 초대 참여
모든 사진은 X 자리표시자이며, 로그인·사진 선택·공유·업로드·저장은 모의 동작입니다. 데이터는 이 브라우저 탭의 세션에만 저장됩니다. 다른 탭·기기와 연결되지 않습니다.

형식: 화면별 HTML + 공유 CSS/JavaScript. 브라우저에서 흐름·권한·상태를 검토하기 위해 사용합니다. 실제 앱 구현 단계에서는 Expo를 사용합니다.
