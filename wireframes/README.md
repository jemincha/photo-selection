# 사진 셀렉 와이어프레임

`index.html`에서 시작한다. 화면당 HTML 파일 하나와 공유 CSS/JavaScript로 구성된 독립적인 시안이다. 외부 라이브러리, 서버, 실제 이미지가 필요하지 않다.

로컬 미리보기: 프로젝트 루트에서 `python -m http.server 4173 --bind 127.0.0.1`, 이후 `http://127.0.0.1:4173/wireframes/index.html`.

기본 화면은 390×844. 좁은 화면에서는 폭을 조절한다. 데스크톱에서는 화면 목록, 역할·참여 환경·상태 선택기, 이동 주석을 함께 보여준다.

요청자: S0 → S1 → S2 → S4 → S3 → S5 → S7 → S8.
친구: W1 → S5 → S6 → S5 → 확정 후 S8.

같은 요청 안에서 검토용 역할을 바꾸면 해당 요청의 상태를 공유한다. 서로 다른 요청의 데이터는 분리하고, 기기·탭 간 동기화는 하지 않는다. 체험 초기화 버튼으로 예시 데이터로 돌아간다.

홈의 내 요청·친구 요청은 독립적인 데이터를 가진다. 요청 카드로 이동하면 역할이 자동으로 정해진다. 화면 밖 역할 선택기는 해당 요청의 권한 차이를 확인하는 검토 도구일 뿐 제품 기능이 아니다.

S6 상세 화면: 한 장씩 표시하며 왼쪽 스와이프는 다음, 오른쪽은 이전 사진. 스와이프는 분류를 바꾸지 않는다. 하단 별로·글쎄·좋아 버튼으로 분류한다. 글쎄와 아직 안 고름은 구분하며 세 분류는 상호 배타적이다. 선택 취소·직전 분류 되돌리기를 제공한다. 분류 후 사진은 유지한다. 세로 이동·짧은 드래그·취소는 사진 이동을 수행하지 않는다. 사진 영역의 좌우 방향키로도 탐색한다. 확정 후 분류와 되돌리기는 차단하지만 사진 탐색은 허용한다.

최종 확정 후 반응은 읽기 전용이다. 친구에게 업로드·확정·저장 기능은 제공하지 않는다. 웹 참여자에게 결과 화면의 앱 홈 버튼을 제공하지 않는다.

검토 상태는 합성 상태이다. 확정됨 상태 선택기는 해당 화면만 변경하며, 실제 흐름에서 확정하려면 요청자가 S7에서 확정 버튼을 눌러야 한다.

확정 후 수정·사진 추가 정책, 친구의 원본 다운로드, 보관 기간·용량 상한은 개발 전 추가 검토 대상이다. 실제 사진·Apple 로그인·Storage·권한·네이티브 저장은 다음 기술 검증 단계의 범위이다.
